# DevDashboard

DevDashboard is an all-in-one desktop dashboard that provides useful system information and productivity tools in one place.

## Features

- **System Notifications** – View system notifications directly from the dashboard.
- **CPU Usage** – Monitor your CPU usage in real time.
- **RAM Usage** – Keep track of your memory usage.
- **Disk Usage** – Monitor your disk space and usage.
- **Network** – View network activity and information.
- **Pomodoro Timer** – Set up Pomodoro sessions to improve productivity.
- **Alarm Clock** – Create alarms with customizable alarm sounds.
- **Stopwatch** – Start, stop, and track time with a built-in stopwatch.
- **Custom Alarm Sounds** – Choose your own sounds for Pomodoro timers and alarms.
- **Clipboard History** – View your clipboard history and click any entry to copy it again.
- **Custom Hotkeys** – Create keyboard shortcuts to quickly launch actions and features.

## Overview

DevDashboard combines system monitoring, productivity tools, and quick-access features into a single dashboard, making it easier to keep track of your system and manage your daily tasks.

## Goals

The goal of DevDashboard is to create a simple, useful, and customizable dashboard that brings everything you need into one place.
